# Orbita Studio 0.3.5

Ao concluir uma execução em **Permissão total**, o Orbita aceita automaticamente o diff salvo em Git na branch da missão. O painel **Diff & Evidências** registra o aceite e mantém a opção **Reverter**.

No modo **Autônomo**, você pode aceitar o diff manualmente para registrar essa revisão. A missão termina assim que o agente conclui o trabalho. O histórico registra a revisão por missão, e a integração da branch ao repositório original é uma operação separada do Git.

Abra `Orbita.Desktop.exe` ou `Abrir-OrbitaStudio.cmd` no pacote Windows. Para atualizar no mesmo endereço, aguarde a missão terminar e encerre a versão anterior. Os projetos e checkpoints ficam na mesma pasta de dados.
