# Orbita Studio 0.3.2

Abra `Orbita.Desktop.exe` ou `Abrir-OrbitaStudio.cmd` no pacote Windows. O seletor **Simples / Avançado** fica na barra superior. Você também pode usar `Ctrl+J` no desktop.

- **Simples** exibe os projetos e as conversas na lateral. A área principal mostra a conversa e os controles de execução, com abas para as alterações e a atividade. O plano fica recolhido e pode ser aberto no mesmo chat.
- **Avançado** exibe as três colunas, cotas, arquivos do projeto, worktrees, diff com evidências e o console Antigravity. É a visão de trabalho para acompanhar etapas e revisar o código.

A troca mantém a missão selecionada, a aba, o rascunho e o trabalho em execução. A preferência fica salva no cliente. Uma instalação nova começa no Simples. Se este cliente já tinha preferência pelo Foco no chat na 0.3.1, o Orbita usa essa preferência para escolher a primeira visualização.

Para atualizar no mesmo endereço, aguarde a missão terminar, encerre o serviço anterior e inicie a nova versão. Projetos, worktrees e checkpoints continuam na pasta de dados existente. Os modos de execução estão descritos no [guia da 0.3.1](ORBITA_STUDIO_0.3.1.md).
