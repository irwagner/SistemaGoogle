# Orbita Studio 0.3.7

Na conversa da missão, selecione **Permissão total** e peça ao Antigravity para abrir o aplicativo compilado. O Antigravity pode chamar a ferramenta local do Orbita, que inicia o `.exe` do worktree na área de trabalho do Windows. **Atividade** registra o PID e informa se o Orbita identificou uma janela visível.

Para abrir diretamente, use **Abrir aplicativo** ao lado do título da missão e informe o caminho do `.exe`. O botão funciona sem uma chamada ao modelo.

Atualize pelo pacote Windows e abra `Orbita.Desktop.exe` ou `Abrir-OrbitaStudio.cmd`. Os dados são carregados da mesma pasta dos projetos existentes.
