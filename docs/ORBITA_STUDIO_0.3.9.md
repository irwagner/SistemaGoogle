# Orbita Studio 0.3.9

Selecione o projeto no menu à esquerda e clique em **Criar missão** ou no **+** ao lado de **Conversas**. O formulário mostra o nome do projeto selecionado.

Em um repositório Git recém-iniciado, o Orbita cria uma base própria para a missão usando os arquivos já preparados no Git. Se o índice estiver vazio, a missão começa vazia. Você pode enviar os arquivos de referência da pasta original pelo botão **Anexar**.

Em projetos com histórico, a missão começa no último commit da branch aberta. Cada missão recebe sua própria branch e pasta de trabalho.
