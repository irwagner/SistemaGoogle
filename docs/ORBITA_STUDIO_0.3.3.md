# Orbita Studio 0.3.3

O topo mostra **Login direto do CLI** quando uma missão roda com o login do Antigravity instalado no Windows. O indicador do pool é separado. Com o pool desligado, ele pode mostrar **Pool em espera** ao mesmo tempo que o CLI está trabalhando.

Para usar rotação no próximo pedido, abra **Contas**, inicie o pool e selecione duas ou mais contas na ordem desejada. Quando o pool gerencia a sessão, o topo identifica a conta em uso. O painel de cotas mostra as medições fornecidas pelo pool.

Abra `Orbita.Desktop.exe` ou `Abrir-OrbitaStudio.cmd` no pacote Windows. Aguarde a missão terminar antes de encerrar a versão anterior e abrir a nova. O Orbita usa os mesmos projetos, worktrees e checkpoints.
